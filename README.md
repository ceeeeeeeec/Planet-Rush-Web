# Planet Rush Web

Web-first game project.

Milestone 0.1 is a playable browser prototype with a destructible block grid, autonomous mining, manual drag steering, credits, special blocks and planet reset.

Run locally with Node.js: npm install && npm run dev

The web version is the primary development target. Android/iOS ports can follow later.

## Browser deployment
The web build is deployed to GitHub Pages from the `main` branch via GitHub Actions.
